## Current status

Planning only: no application has been implemented. The roadmap is a proposal, not authorization to begin coding or evidence of paid work.

## Claude Code workflow

1. Work on one agreed roadmap task at a time and confirm its acceptance criteria.
2. Explain a small implementation plan and identify relevant files before making substantial changes.
3. Keep changes focused; add meaningful tests and run them when feasible.
4. Report what changed, tests actually run, and remaining issues.
5. Propose architectural changes rather than silently overriding project decisions.
6. Never claim that work qualifies for Alignerr compensation; only Alignerr can determine that.

## Alignerr evaluation boundary

Until the project has been explicitly accepted and terms verified, do not assume any development activity is payable. During any potential Alignerr sessions:
- Use **fictional/synthetic personas only**; do not process personal information from real users.
- Do not onboard actual users or connect real accounts, health records, calendars, financial data, or personal journals.
- Use mock AI responses and fake credentials in demos and tests.
- Keep real API keys, confidential information and private user data out of repositories, terminal output, prompts, logs and shared development traces.
- Confirm that the proposed project and transcript-sharing arrangements are permitted under the actual program agreement before work begins.

Follow AGENTS.md for privacy, security, autonomy, and cost safeguards.
